# Site Ada lovelace

Ada Lovelace foi uma matemática inglesa considerada a primeira programadora da história. No século XIX, ela trabalhou com Charles Babbage e percebeu que suas máquinas poderiam fazer muito mais do que cálculos. Ada criou um conjunto de instruções para a Máquina Analítica, considerado o primeiro algoritmo destinado a ser processado por uma máquina. Sua visão ajudou a antecipar o funcionamento dos computadores modernos e fez dela uma importante pioneira da tecnologia.


# Ferramentas utilizadas no desenvolvimento do site

Eu desenvolvie o site sobre Ada Lovelace em um curso que estava fazendo na Programaria que é uma instituição que da curso de graça.
Inicilamente utilizei HTML, CSS e JavaScript o HTML foi responsável pela estrutura e organização dos conteúdos, o CSS  pela aparência visual
e o javaScript pela interatividade da pagina.
Agora transformei o projeto utilizando React e Tailwind CSS, isso possibilitou estilizar a página diretamente no código, tornando o desenvolvimento mais rápido e responsivo.
Também utilizei o Vite, uma ferramenta que facilita a excução do projeto e permite visualizar as alterações em tempo real.
